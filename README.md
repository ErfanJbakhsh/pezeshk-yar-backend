## Pezeshk Yar — Backend

Pezeshk Yar is a simple medical appointment booking system that allows users to register, log in, browse doctors, and book appointments from their available time slots. Users can also view and cancel their appointments.

This repository contains the backend of the project, developed using **FastAPI** and **PostgreSQL**. It handles user authentication, doctor information, available time slots, and appointment management.

The booking system prevents multiple users from booking the same time slot, ensuring that each slot can only be reserved by one user at a time.

### Technologies

- FastAPI
- PostgreSQL
- SQLAlchemy
- JWT Authentication
- Pydantic
- Python
